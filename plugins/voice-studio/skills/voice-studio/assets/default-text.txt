Decode 有一个隐藏的麻烦。
生成第 7 个 token 时，它的 Q 要和前面 6 个 token 的 K、V 打交道。
如果什么都不存，就得把前面 6 个 token 重新算一遍，才能拿到它们的 K 和 V。
生成下一个，又要重算 7 个。越往后，重复的工作越多。
可是，因果遮罩保证了：历史 token 的 K 和 V，不会因为后面来了新 token 而改变。
既然不变，就把它们存起来。这就是 K V Cache。
每一步，只为新 token 算一份 K 和 V，追加到缓存末尾；历史部分直接从缓存读取。
重复计算省掉了。代价是显存：缓存会随着上下文变长、并发变多而持续增长。
这就是推理系统里最核心的一笔交易：用显存，换掉重复计算。
